# Лабораторная работа 3. Tower Defense

3D-игра на **Godot 4.7.2 .NET и C# (.NET 8)**, расширяющая прототип из практики 3. Поведение объектов собирается из отдельных узлов-компонентов.

## Запуск

1. Открыть Godot с поддержкой **.NET** и импортировать `project.godot`.
2. Дождаться импорта и собрать C#-проект в редакторе.
3. Нажать **F5**. Главная сцена — `Scenes/Level.tscn`.

Нужен .NET SDK с поддержкой `net8.0`. Сборка из терминала:

```powershell
dotnet build TowerDefense.csproj
```

## Управление

Нужно защищать синее ядро от бесконечных волн врагов. Гибель игрока или ядра завершает игру.

| Клавиша | Действие |
| --- | --- |
| WASD | Движение |
| Мышь | Поворот оружия |
| ЛКМ / пробел | Стрельба |
| B | Включить призрак башни; повторное нажатие — построить |
| 1 / 2 / 3 | Обычная / взрывная / замораживающая башня |
| Esc | Отменить строительство |
| R | Начать заново |

Призрак появляется перед игроком и перемещается вместе с ним. Зелёный цвет разрешает постройку, красный означает занятое место, границу поля или нехватку металла. У призрака нет коллизий и оружия. Во время строительства игрок не стреляет.

## Башни, враги и металл

Все башни неподвижны. Игрок и башни зелёных оттенков, враги красные, ядро синее.

| Башня | Действие | Цена | Металл при уничтожении |
| --- | --- | --- | --- |
| Обычная | Пули с уроном 2 | 30 | 8 |
| Взрывная | Взрыв радиуса 3,5 с уроном 4 по каждой цели | 50 | 12 |
| Замораживающая | Урон 1, снижение скорости до 35% на 3 секунды | 40 | 10 |

**Crawler** атакует при контакте и даёт 12 металла при уничтожении. **EnemyShooter** подходит на дистанцию стрельбы и даёт 18 металла. Без видимой цели враги идут к ядру. Первая волна начинается через 12 секунд, следующие — каждые 15 секунд; количество врагов растёт с 3 до 12.

Начальный запас — 100 металла. Цены и награды задаются в `MetalComponent` сцен объектов. `GameManager` отслеживает их удаление через `TreeExiting` и начисляет награду один раз. При поражении и перезапуске начисление отключается. Неудачная постройка не расходует металл.

## Структура сцен

Каждый тип объекта хранится в отдельной сцене в `Scenes/`.

| Сцена | Основные компоненты |
| --- | --- |
| `Level` | `GameManager`, поле, камера, свет, игровые объекты, `EnemySpawner`, HUD |
| `Core` | `HealthComponent` |
| `Player` | `HealthComponent`, `PlayerController`, `ShootComponent`, `BuildComponent` |
| Три сцены башен | `HealthComponent`, `VisibilityComponent`, `ShootComponent`, `MetalComponent` |
| `Crawler` | `HealthComponent`, `VisibilityComponent`, `MoveComponent`, `DamagingComponent`, `MetalComponent` |
| `EnemyShooter` | `HealthComponent`, `VisibilityComponent`, `MoveComponent`, `ShootComponent`, `MetalComponent` |
| Четыре сцены пуль | `Bullet`, меш и дочерний компонент урона с коллизией |
| `Explosion` | Видимая сфера, `ExplosionAreaComponent`, `LifetimeComponent` |

У тел есть меши и коллизии, у стреляющих объектов — `MuzzleVisual` с точкой выстрела `MuzzleMarker`. Группы `Allies` и `Enemies` определяют сторону, а физические слои 1 и 2 фильтруют столкновения.

## Назначение классов

Исходники находятся в `Scripts/`. Компоненты объявлены `[GlobalClass]`, настраиваемые параметры — `[Export]`.

| Класс | Назначение |
| --- | --- |
| `HealthComponent` | Здоровье, получение урона, сигнал смерти и удаление объекта |
| `VisibilityComponent` | Учёт целей в области и выбор ближайшей |
| `MoveComponent` | Движение врага, остановка у цели и временное замедление |
| `ShootComponent` | Автоматическая или ручная стрельба, создание пуль с заданным интервалом |
| `DamagingComponent` | Общая логика урона, проверка группы, одноразовая или контактная атака |
| `ExplosionComponent` | Создание области взрыва при попадании |
| `ExplosionAreaComponent` | Однократный урон каждой цели в области взрыва |
| `FreezeComponent` | Урон и временное замедление через `MoveComponent` |
| `Bullet` | Полёт и время жизни пули |
| `LifetimeComponent` | Удаление временного эффекта |
| `PlayerController` | Движение игрока и прицеливание мышью |
| `BuildComponent` | Выбор башни, призрак, проверка места и постройка |
| `MetalComponent` | Цена, награда и регистрация объекта в менеджере |
| `GameManager` | Состояние игры, металл, поражение и перезапуск |
| `EnemySpawner` | Создание волн врагов |
| `GameHud` | Отображение здоровья, ресурсов и сообщений |

`GameManager.Instance` задаётся в `_EnterTree()` и ссылается на менеджер текущего уровня.

### Урон и композиция

`DamagingComponent` наследуется от `Area3D` и используется как на пулях, так и на Crawler. Пуля отвечает только за полёт; контактный враг использует `OneShot = false` и повторяет удар каждые 0,8 секунды.

`ExplosionComponent`, `ExplosionAreaComponent` и `FreezeComponent` наследуются от `DamagingComponent`. Взрыв поражает каждую цель один раз. Заморозка временно меняет скорость и цвет врага, затем восстанавливает их; повторное попадание обновляет время эффекта.

Тип башни определяется сценой снаряда в `ShootComponent`. Поведение врага зависит от набора компонентов: стрелок имеет `ShootComponent`, Crawler — контактный `DamagingComponent`.
